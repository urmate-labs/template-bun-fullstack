# Bun Full-stack Monorepo

Author: Urmate

Two Bun services in one workspace, one for the interface and one for JSON routes.

## Stack

`Bun`, `TypeScript`, `HTML`, `CSS`

## Theme

- Name: Citrus Console
- Primary: #6a9f1f
- Accent: #ff6b35
- Motion: 180ms quick rise, runtime scan line

Theme tokens are also stored in `.urmate/theme.json` for Urmate Builder.

## Commands

| Task | Command |
| --- | --- |
| install | `bun install` |
| dev | `bun run dev` |
| build | `No build step` |
| preview | `http://localhost:3000` |

## Details

- Bun web server
- Bun API server
- Shared theme tokens
- Fast local loop
